🍔 FoodieHub -- Food Website

A modern and responsive food ordering website built with HTML,
Tailwind CSS, JavaScript, and Font Awesome.

FoodieHub provides a clean food-ordering interface where users can
browse food items, search products, add items to an order, view the
total price, and use a light/dark theme.

🛒 Order System

Users can:

Browse food products.

Click ADD+ on a food item.

See selected products in Your Order.

View the calculated total price.

Continue toward checkout.

The home page contains the order panel with an order list, total price
and checkout button. citeturn3view0
